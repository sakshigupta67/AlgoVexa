# AlgoVexa 🥽

### Immersive 3D Algorithm Visualization and Learning

**AlgoVR** is an interactive educational application that uses **Virtual Reality and 3D Computer Graphics** to visualize fundamental algorithms inside a virtual Computer Science laboratory.

The system transforms algorithmic operations into interactive 3D objects, animations, and visual states, helping learners observe and understand how algorithms execute step by step.

## ✨ Features

- 🧩 **3D Virtual Computer Science Laboratory**
- 🔄 **Sorting Visualization**
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
- 🔍 **Searching Visualization**
  - Linear Search
  - Binary Search
- 🕸️ **Graph Traversal Visualization**
  - Breadth-First Search (BFS)
  - Depth-First Search (DFS)
- 🎬 **Real-Time Algorithm Animations**
- 🎯 **Interactive Algorithm Execution**
  - Start
  - Pause
  - Resume
  - Reset
  - Step execution
- 🧱 **Interactive 3D Array Blocks**
- 🔗 **3D Graph Nodes and Edges**
- 🎨 **State-Based Visual Highlighting**
- 🥽 **VR Interaction using OpenXR**
- 🖥️ **Desktop Simulation Mode**
- 📝 **Practice and Assessment Activities**
- 💬 **Instant Feedback**
- 📊 **Algorithmic State Synchronization with Visualization**

## 🎯 Algorithms To Be Covered

| Category | Algorithms | Complexity |
|---|---|---|
| Sorting | Bubble Sort, Selection Sort, Insertion Sort | O(n²) |
| Searching | Linear Search | O(n) |
| Searching | Binary Search | O(log n) |
| Graph | BFS, DFS | O(V + E) |

## 💡 Core Concept

**Computation → Visualization → Interaction → Learning**

AlgoVR connects algorithmic state changes directly with graphical transformations, allowing learners to observe comparisons, swaps, searches, node visits, and traversal operations as dynamic 3D processes.
